# Casa d'Autore

Сайт интернет-магазина итальянской мебели для Казахстана: каталог с фото, фильтры по категориям и комнатам, карточка товара с галереей и выбором отделки, цены в тенге, переключатель RU / KZ.

> **Демо-проект.** Показывает вёрстку, интерфейс и работу каталога. Это не действующий
> магазин: телефон, цены, адреса шоурумов и сроки — условные, фотографии взяты с Unsplash
> как образцы. Что именно нужно заменить перед настоящим запуском — в конце этого файла
> и подробно в [STATUS.md](STATUS.md).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Готовый сайт одним файлом, фото встроены. Открывается в браузере без сервера. |
| `src/site-template.html` | Исходник сайта: разметка, стили, данные товаров, скрипты. Вместо фото стоят метки `@@имя@@`. |
| `img/` | Фотографии, которые подставляются в шаблон. |
| `build.py` | Собирает `index.html` из шаблона и фото. |
| `STATUS.md` | Что уже сделано и что осталось. Читать перед доработкой. |
| `docs-concept.html` | Концепт-документ: структура страниц, тексты, ТЗ на 360° и конфигуратор, правила съёмки. |

## Как править

1. Меняйте текст, цены и товары в `src/site-template.html`. Товары описаны в массиве `P` внизу файла.
2. Новое фото положите в `img/` как `имя.jpg` и укажите в шаблоне как `@@имя@@`.
3. Соберите сайт:

```
python build.py
```

## Что заменить перед запуском

- Телефон `+7 700 000 00 00` и номер WhatsApp в ссылках `wa.me`.
- Адреса шоурумов, почту, цены и сроки.
- Фотографии: сейчас использованы снимки с Unsplash как образцы.
